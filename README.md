# ICDMW2026-BrailleGuide

**Author:** Yuxiang Chen

**Abstract:**
Visual impairment can significantly limit independent environmental perception, while many existing assistive systems provide only limited information from visual input. Conventional systems often depend on object detection or Optical Character Recognition (OCR), which may identify individual objects or text but cannot always explain scene context, userrelevant relationships, or potential actions. Vision-Language Models (VLMs) offer a promising alternative by jointly interpreting visual and linguistic information. This paper proposes BrailleGuide, a split-form wearable assistive system that connects a VLM-based Visual Perceptor unit with a Handheld Terminal containing a refreshable Braille display, buttons, and a joystick. The perception unit captures environmental images, sends them to an online VLM, and converts the generated descriptions into tactile feedback. The main contributions are a VLM-based accessibility pipeline for environmental description, a lightweight split architecture separating perception from tactile interaction, and a prototype evaluation that demonstrates the feasibility of VLMassisted environmental awareness through Braille feedback. 

**Index Terms:**
vision-language model, assistive system, visually impaired users, environmental understanding, tactile Braille display
